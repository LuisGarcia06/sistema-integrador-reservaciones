Prepara tu instalación de ensayo

Servidor y cliente deben estar instalados con /LABONLY en esta misma VM. Conserva la instantánea y mantén la VM sin acceso a redes empresariales.

La detección de VirtualBox comprueba el entorno; no certifica su aislamiento de red. Esta herramienta no importa datos ni activa integraciones.
