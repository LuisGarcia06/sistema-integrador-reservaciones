# Sistema Integrador de Reservaciones

Sistema Integrador de Reservaciones para Community Tours Sian Ka'an.

## Tecnologías

- Electron
- HTML
- CSS
- JavaScript
- Node.js
- Express
- PostgreSQL

## Estado del proyecto

Actualmente en etapa de desarrollo e implementación.

## Estructura

- `frontend/`: interfaz de usuario.
- `backend/`: API y lógica de negocio.
- `database/`: scripts de PostgreSQL.
- `electron/`: configuración de la aplicación de escritorio.
